# Art

Build-referenced art: assets that reach the game through a direct reference from a
ScriptableObject, prefab or scene, and therefore only ship if something actually points at them.

- `Pokemon/` — PokeAPI official-artwork sprites for the 183-species roster, 256px, one PNG per
  species id. No longer drawn by default — `Pokemon-Sprites/` above replaced it in every screen —
  but kept as the fallback beneath the battle sprites, and as the illustration for anywhere that
  wants it. Referenced by each `PokemonSpeciesDefinitionAsset.Sprite`
  (`Assets/Content/Species/*.asset`), which the roster importer fills in by id. Every species is
  authored now, so all 183 are referenced and ship — the reference (rather than a `Resources` path
  string) is kept because a wrong one is visible in the Inspector instead of a silent runtime null.
  Import settings are applied from code by `Assets/Editor/PokemonSpriteImportProcessor.cs`; don't
  hand-tune them per file.

- `Pokemon-Sprites/animated_sprites/` — the game-style battle sprites, `front/` and `back/`, one
  animated GIF per species named by PokeAPI name slug (`pikachu.gif`, `ho-oh.gif`). Referenced by
  each `PokemonSpeciesDefinitionAsset.FrontSprite` / `.BackSprite`, filled in by
  `SpeciesRosterImporter` matching the slug. Import settings come from
  `Assets/Editor/BattleSpriteImportProcessor.cs` — Point-filtered and uncompressed, the opposite of
  `Pokemon/` next door, because these are ~50x46 pixel art rather than smooth illustration.

  **Sizes are meaningful and must not be normalised.** The set is drawn at true relative scale —
  Ralts is 23x39 and Lugia 153x94, because Lugia is about four times the size. The battlefield
  multiplies each sprite's own pixels by one shared factor (`BattleSpriteScaler`) rather than
  fitting each to a box, so resizing these files to a uniform canvas would destroy the proportions
  the art already encodes.

  **These are what the game draws now.** The front sprite is used everywhere a Pokémon appears;
  the back sprite only for the player's own Lead and Support on the battlefield. `Pokemon/` below
  is the fallback beneath both.

  Two caveats worth knowing. **Unity imports the first frame of a GIF only** — there is no built-in
  animated-GIF support, so these are stills despite the folder name; the GIFs are kept as the source
  for a future frame-extraction step. And the set covers **181 of the 183** curated species: the two
  gendered Nidoran have no sprite, while Pichu and Magmortar are present but aren't on the roster
  (`fetch_animated_sprites.py` worked from a slightly different list). The two Nidoran fall back to
  their artwork; `ContentIntegrityTests` pins this so the gap can't widen silently.

- `Backgrounds/` — full-screen backdrops. Today only `BattleForest.png`, a 640x360 placeholder
  pixel-art forest generated by `tools/generate_battle_background.py` and referenced by the Battle
  scene (`BattleSceneBuilder`). Imported Point-filtered and uncompressed by
  `Assets/Editor/BackgroundImportProcessor.cs`, and deliberately not atlased (one image drawn
  once gains nothing from packing).

**This is not where runtime-loaded art goes.** Sprites resolved by string path at runtime live
under `Assets/Resources/Sprites/` instead (UI chrome, type badges, node icons) — see
`Pets.UI.Theme`. Everything in `Resources` ships whether or not it's referenced, which is exactly
why the species sprites are here and not there.
