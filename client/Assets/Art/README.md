# Art

Build-referenced art: assets that reach the game through a direct reference from a
ScriptableObject, prefab or scene, and therefore only ship if something actually points at them.

- `Pokemon/` — PokeAPI official-artwork sprites for the 183-species roster, 256px, one PNG per
  species id. Referenced by each `PokemonSpeciesDefinitionAsset.Sprite`
  (`Assets/Content/Species/*.asset`), which the roster importer fills in by id. Every species is
  authored now, so all 183 are referenced and ship — the reference (rather than a `Resources` path
  string) is kept because a wrong one is visible in the Inspector instead of a silent runtime null.
  Import settings are applied from code by `Assets/Editor/PokemonSpriteImportProcessor.cs`; don't
  hand-tune them per file.

- `Backgrounds/` — full-screen backdrops. Today only `BattleForest.png`, a 640x360 placeholder
  pixel-art forest generated by `tools/generate_battle_background.py` and referenced by the Battle
  scene (`BattleSceneBuilder`). Imported Point-filtered and uncompressed by
  `Assets/Editor/BackgroundImportProcessor.cs`, and deliberately not atlased (one image drawn
  once gains nothing from packing).

**This is not where runtime-loaded art goes.** Sprites resolved by string path at runtime live
under `Assets/Resources/Sprites/` instead (UI chrome, type badges, node icons) — see
`Pets.UI.Theme`. Everything in `Resources` ships whether or not it's referenced, which is exactly
why the species sprites are here and not there.
